# Bundled fonts

Latin WOFF2 subsets of Newsreader, IBM Plex Sans, and IBM Plex Mono, originally served by Google Fonts and cached by Next.js. Bundling them makes builds independent of Google Fonts network availability. The files are unmodified.

Newsreader: variable normal and italic (200–800). IBM Plex Sans: normal used at 400–600. IBM Plex Mono: normal 400 and 500.

Each family is distributed under the accompanying SIL Open Font License. Upstream license sources:

- https://github.com/google/fonts/tree/main/ofl/newsreader
- https://github.com/google/fonts/tree/main/ofl/ibmplexsans
- https://github.com/google/fonts/tree/main/ofl/ibmplexmono
